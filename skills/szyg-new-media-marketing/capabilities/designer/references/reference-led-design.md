# 参考拆解与再设计

当用户给图、说“学习这套”“按这个水准重做”或否定上轮审美时，先拆解实际参考，不重复只选风格名的过程。

## 从一张参考读出什么

每张记录：用途、第一眼和下一眼的顺序、人物/产品与文字的面积关系、字体搭配、光线与颜色、材料纹理、信息密度、行动入口。用户没有指定数值时可估计比例作为制作起点，再以实际图校准；不要把估计说成精确测量。

解释其工作机制，例如“人物暗色肩部承托白色竖向书法”“亮光连接时间轴”“图钉、纸张阴影与人物白边形成拼贴”。把这些机制转成当前品牌可以执行的构图和制作要求。

把输入明确分为：用户自己的身份/产品素材、风格参考、业务事实/证据、编辑目标。人物身份只来自当前品牌素材；风格参考中的人脸、身份、Logo、日期、价格、名额、评价、二维码不移入新稿。生成演绎的人像不能作为客户效果或现场记录。

## 逐层拆解后再转化

需要按模板转化时，把视觉拆成能独立判断的组件，例如背景材料、主标题、主体、标签、连线、详情块、品牌与行动区；分组数量只是分析口径，不能冒称真实PSD图层数。每组写清“原图作用→本项目替换元素→保留的构图机制”。

参考中的主体不等于本项目必须采用的人物或物件。先确认本项目要不要真人、品牌资产是什么，再保留其图文关系、字形或空间机制。不要只把蓝改黄、把名字替换，就声称完成了同风格转化。多方案应在构图和材料机制上形成区别，同时保持当前业务文案一致。

## 图文与材料共同设计

- 人物是主视觉时，先决定尺度、裁切、表情与光线，再安排主字落在背景或深色衣物上的位置，保护脸部关键特征。
- 书法、窄体、宋体与黑体各有表达任务。主字体适合主题，说明字体服务可读性；使用有许可的字体并保留许可。
- 纸张、光影、颗粒和数字纹理有对应的传播气质。选一种主要材料语言，避免把纹理、发光、图标和线条同时堆上去。
- 主宣传抓注意、产品场景解释能力、详情长图展开条件、案例图展示证据。内容较多时分出物料，不能让每张都承担全部工作。
- 当前用户要求整张大模型生图。把主视觉、字体、准确文案和入口在同一次生成中完成，按 [整张海报生图](whole-poster-generation.md) 核对与修订；可编辑范围以实际输出为准。

## 当前参考库与检查

通用候选从[57项索引](reference-library.md)选取，外部条目按作者与出处回看。既有品牌案例仅在对应项目读取，不进入通用库。

原尺寸和手机尺度都查看。主图检查人物身份、主字是否压脸、核心文案是否能迅速识别；长图检查信息节奏、小字和证据区。技术通过不代表视觉关系成立，设计判断与用户认可分别记录。
