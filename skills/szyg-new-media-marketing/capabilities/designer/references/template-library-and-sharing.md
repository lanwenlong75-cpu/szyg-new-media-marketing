# 通用模板、外部参考与品牌成品

盘点模板、建立挑选页或准备分享Skill时，先区分三种材料：

| 材料 | 如何使用 | 分享边界 |
|---|---|---|
| 通用方法与空白模板 | 不依赖某个品牌，可替换为接收者自己的内容 | 可纳入通用Skill；字体、代码和第三方资产仍按各自许可保留来源 |
| 外部作品参考 | 观察构图、字形、图文关系与材料，保留作者和原出处 | 不能冒称自有或可编辑模板；未确认再分发许可时只保留来源链接和可复用的方法说明，原图不随包分发 |
| 品牌成品与生产配置 | 成品、候选、真实文案、价格权益、排期、二维码、人物及品牌色配置 | 留在对应私有项目；不进入通用模板数量、通用模板挑选页或默认分享清单 |

用户认可一张成品，表示该品牌和用途下的审美反馈，不会把成品自动变成公共模板。品牌模板是该对象的私有生产配置，也不等于公共模板。

模板挑选页使用通用模板或外部参考目录作为唯一数据源，不能为了凑数量把产出成品拼入。若页面原来混入品牌成品，移出当前目录与导出去留清单，保留原项目文件和已有通用项的选择；本机历史清单仅留作私有记录。

分享Skill按可分发文件白名单组装，保留设计判断、审美方法、工作流程、空白模板与已获授权资产。排除服务对象档案、品牌成品、原始业务资料、人物资产、任务与选择记录、反馈原话、客户附件、账号标识及本机绝对路径。自用入口中的对象绑定、确认规则原文和私有案例链接不能整包复制；通用版从接收者当前项目读取其自己的对象与素材。

打包后再回读压缩包的实际目录、正文与图片，核对业务专名、默认对象、本机路径、品牌资产和未获许可的参考原图。只改页面标签、只改品牌名或只排除一张海报，均不能证明分享包已完成隔离；未实际生成和验收的包不报告为可分发。
