# 57项通用设计参考库

当前保留7种基础风格与50个外部作品参考。S/R编号保持不变。它们提供设计方法，不是57份可编辑源稿。用途与文案密度标签是转化判断，不是原作者的分类。

先明确用途、真实内容、信息量和已有主体，再用下列工具缩小范围。没有Python时直接按下面的类别索引或查询JSON。

```text
python scripts/select_references.py --purpose 活动 --density 低 --query 纸片 --limit 5
python scripts/select_references.py --purpose 排期 --density 高 --limit 6
python scripts/select_references.py --ids S11 R08 R37
```

命令从本模块根目录运行，脚本依自身位置读取库，不依赖工作区、网络或用户账号。查找失败时放宽条件，不能从已退出旧模板补数。输出只提供候选及适用依据，最终仍实际查看原出处或用户参考。外部链接不可访问时按方法做独立设计，标明本次未看原图，不宣称复刻完成。

选定一项主要机制，必要时补一种信息组织方法。把“机制→当前内容替换→阅读顺序→不用的部分”写入空白简报；不要把多个参考的发光、纸片、网格和立体字全叠上去。严格保留当前品牌主色与真实资产，不复制原作标题、身份和标志。
