# Data Editorial

## Intent

Create a polished editorial poster that turns information, metrics, or insights into a clear visual argument with refined charts and callouts.

## Typography

- Use crisp sans-serif hierarchy with numeric emphasis.
- Make key numbers large and editorial.
- Use labels and captions sparingly.
- Keep chart text readable and minimal.

## Palette

Neutral editorial base with one or two data accents: blue, green, orange, violet, red. Avoid rainbow dashboards unless required.

## Imagery

Use charts, callout cards, maps, abstract data shapes, icons, or one conceptual image paired with data modules.

## Texture / Material

Clean print/editorial surface, subtle grid, light paper grain, fine rules, precise labels.

## Composition Rules

- Start with a strong headline insight.
- Use data visuals as supporting evidence, not decoration.
- Keep chart forms simple and legible.
- Use modular hierarchy for multiple data points.

## Avoid

Dashboard clutter, fake random numbers, overcomplicated charts, tiny labels, excessive icons, and decorative data noise.
