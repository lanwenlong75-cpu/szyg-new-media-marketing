# Monochrome Typographic

## Intent

Create a high-contrast black-and-white poster where typography, spacing, and rhythm provide all visual impact.

## Typography

- Use large typographic scale, weight contrast, tracking, and line breaks.
- Combine sans-serif weights or serif/sans contrast with discipline.
- Treat text as image.
- Keep small text minimal and sharply aligned.

## Palette

Black, white, off-white, charcoal. Optional single gray tone only.

## Imagery

No imagery required. Optional line, rule, shape, shadow, or abstract typographic crop.

## Texture / Material

Matte paper, subtle grain, ink density, letterpress-like impression, clean print surface.

## Composition Rules

- Build strong hierarchy through scale alone.
- Use tension between dense type and empty space.
- Crop type only when meaning remains clear.
- Align to a strict grid or deliberately break it once.

## Avoid

Decorative filler, weak type hierarchy, gray muddy contrast, random letters, fake glyphs, and long paragraphs.
