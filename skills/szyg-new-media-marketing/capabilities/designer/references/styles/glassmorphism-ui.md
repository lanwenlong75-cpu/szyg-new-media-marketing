# Glassmorphism UI

## Intent

Create a sleek digital poster built from translucent panels, blurred depth, soft gradients, and clean product-interface hierarchy.

## Typography

- Use crisp modern sans-serif typography.
- Place text inside translucent panels with strong contrast.
- Keep labels minimal. Use glass as a compositional material, not as fake interactive UI.

## Palette

Soft gradients: blue, violet, cyan, mint, charcoal, frosted white, silver. Support dark or light modes.

## Imagery

Glass cards, blurred blobs, abstract product panels, icons, floating dashboard-like modules, soft 3D objects.

## Texture / Material

Frosted glass, background blur, subtle border highlights, soft shadow, luminous gradient, depth layers.

## Composition Rules

- Use one hero panel and a few supporting cards.
- Keep transparency effects legible.
- Maintain generous padding and rounded geometry.
- Use depth to guide attention, not decorate everything.

## Avoid

Random fake UI controls, button-like poster CTA labels, and unrequested interactive chrome. Preserve product UI elements explicitly required by the source. Also avoid tiny dashboard text, excessive blur, low contrast, cluttered cards, and generic crypto visuals.
