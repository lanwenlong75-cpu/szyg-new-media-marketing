# 本地资料与工具

本模块提供海报方法、字体和参考图。安装后先从当前项目的 `AGENTS.md`、`.agents/new-media-profile.json` 与员工配置确认业务资料位置；项目中的客户、品牌、产品与授权素材由使用者自行提供。

- 设计基础、流程与事实规则读取当前项目已确认的资料，缺少时先标记待核。
- 原素材和输出放在当前项目明确指定的位置；保留来源、版本与确认状态。
- 字体位于本模块 `assets/fonts/`，出处与许可见 `fonts-provenance.json` 和 `licenses/`。
- 风格参考位于本模块 `assets/references/`，上游设计项目的版本与许可见 `upstream-lock.json`。需要完整编辑器时从对应上游项目另行安装，仓库未包含整套上游运行环境。

换电脑后通过 `portable.py doctor` 检查 Python、FFmpeg、Node、浏览器和相关依赖。具体工具路径在接收者的项目中配置，不能沿用另一台电脑的路径。

价格、有效期、课数和二维码以当前业务已确认事实为准；案例模板不自造业绩，倒计时模板不自造活动截止时间。
