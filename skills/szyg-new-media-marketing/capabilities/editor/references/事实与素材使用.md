# 事实与素材使用

## 事实状态

每条会影响稿件判断的信息记录来源和状态：用户直接确认、来源原文、官方资料、当事人自述、编辑推论、假设情境或待确认。内部来源状态不会因为写进文章就自动变成公开事实。

用户提供的当前定位可以用于文章编辑。历史产品、价格、账号与业务结果使用前核对有效日期；外部案例始终保留主体，不能改写成当前IP的亲历。

技术功能、费用、平台规则、政策以及当前动态需要时效核验。使用官方原始资料，保留链接和查阅日期；核验不了时缩减主张或说明待补，不制造引用。文章含收入或效率数字时核对统计口径、观察窗口、对照和原始来源；不要把一次试用扩展成普遍收益。

## 本地资料调用

从员工配置的知识入口登记表取得本机路径，读取任务所需的最少资料。跨项目资料默认只读。运行文件存在性检查不能代替读取来源正文。

个人研究库：从具体问题检索研究笔记或原书，引用保留书名、章节或页码；区分作者观点、自己的判断和待验证建议。原始PDF保持原样。

案例库：先读调用规则与真源说明，再读常用入口、案例卡和来源原文。保留作者、素材人物、核验状态、公开范围、项目时间及原课件页码。文件数量不能换算成客户数、企业数或成功案例数。

视频库：只有任务需要视频观点或素材时调用；读取逐字稿及实际相关片段的证据，保留说话人和时间位置。不能把机器转写称为人工逐字校对，也不修改其他员工的工程、字幕或发布台账。

指定文章实际使用的材料才复制到当前员工的来源档案，保存原文、来源位置、摘要或哈希及引用位置。外部知识入口是实时依赖，登记“可访问”不代表资料已经入库、完整阅读或可公开。

跨设备依赖当前知识入口配置；旧电脑的绝对路径需重新映射。纯编辑稿可用本地已归档素材运行，不能承诺外部资料盘随岗位skill自动迁移。

## 最终审校

核对正文中的姓名、机构、产品、数字、引号与效果断言，逐项对应来源。必要时区分公开证据与内部参考；公开范围未确认的客户细节不写入可发布正文，保留脱敏需求。

无引用事实的纯编辑建议也要标明作者确认状态。审校记录里的推论和待确认项不混入正文当作作者已认可的经营判断。
