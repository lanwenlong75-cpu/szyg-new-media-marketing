# 图文排版与配图

## 适用范围

当前服务对象启用原题名与图文交付规则时，标题沿用视频原题名，并交付排版和配图；本次明确要求优先。其他对象以其已确认规则为准。源标题从实际登记题名或已核验的平台标题读取，写明来源，不能仅从文件名猜标题。若两者不同，保留对应版本或任务采用依据。

## 图文交付

每篇保存正文Markdown、实际HTML排版、标题摘要、配图文件、来源审校与任务记录。批量任务增加总览入口和包含相对路径素材的压缩包。正文与审校信息分开，复制正文不夹带内部状态或来源路径。离线HTML是本地排版稿，公众号后台录入效果要在真实后台回读。

短段落、明确小标题、少量重点强调与适合手机的行距服务于阅读。长提示词要完整保留条件，可用引文块；不要为排版拆掉有用信息。标题、署名、段落与图注都需检查。每篇按内容需要安排配图，不能仅交无图正文；本批每篇3张是制作选择，不是固定通用数量。

## 配图来源与用途

优先用真实视频画面、已有授权素材和能解释核心方法的原创图解。原视频帧从实际绑定版本抽取，保留媒体路径、版本与时间点。拍到客户、私密聊天或业务数据时先检查素材的已公开与脱敏状态，按实际授权使用。图解注明是内容整理，不伪装产品界面、真实客户效果或收益证据。

清楚的流程图、对比图和文字卡适合用SVG等可编辑图形制作，并导出PNG。需要照片或艺术插画时再选择相应图像生成工具。图片清晰可读，避免正文已有信息的空泛重复；插图与图注对应。原题名含营销修辞时按用户要求保留标题，正文不能把它升级为收益保证。

## 实际检查

核对至少一次手机尺寸实际预览：标题与段落可读，页面没有横向溢出，每张图片加载成功、没有裁掉关键字，图注与内容对应。批量逐页检查图片与链接，缩略总览检查整批视觉；不能用文件存在代替显示验收。

检查正文复制的开头与结尾、是否混入编辑记录，验证下载正文与压缩包；压缩包回读检查文件、图片引用和正文数量。 来源全文保存可回查副本和SHA-256，发布记录未匹配不自动判断未发布；当前新版与已发旧版数据分别记录。保留作者待审阅状态，不以自评或自动检查冒充作者认可。

已验证的制作实例：员工任务EDIT-20261014-003，10篇原题稿、30张PNG、20张SVG与手机预览；脚本和图文复验记录保存在实际任务目录。工具脚本包含该批路径与选片表，复用前需按新任务改输入，不直接当成通用自动写稿工具。
