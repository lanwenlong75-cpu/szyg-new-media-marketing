# 字幕位置：按观众实际看到的画面验收

## 真实反馈与预防

| 遇到的问题 | 根因与执行要求 | 交付前回读 |
| --- | --- | --- |
| 字幕贴底、手机上字太小 | 只在编辑画面里看，没有为发布界面留空间；字号按手机观看尺寸调整 | 最终视频缩到手机尺寸，文字与底板避开底部文案、进度和右侧按钮 |
| 上移字幕后挡住嘴 | 把整批视频套同一高度，忽略近景和镜头变化 | 按镜头选择留白区，检查眼睛、嘴、人物移动及固定标题 |
| MP4已改，工程字幕仍在旧位置 | 只改临时ASS，复制来的规范ASS或说明仍指向旧版 | 实际渲染入口、生效ASS、校对入口和新版说明一致，旧文件标明仅供对照 |
| 切换新版后封面或逐字稿消失 | 附件绑定旧媒体的路径、大小与修改时间 | 逐条核对当前主版、封面来源与全文逐字稿的版本绑定 |
| 旧版对照无法播放 | 旧视频不在新预览页获准读取的目录；同批其他子目录获准不代表它也获准 | 页面中实际切换新旧版并在同一秒解码显示；需要时把独立对照副本放入已登记预览目录 |

## 横向居中

以实际输出画面宽度的一半为默认横向中心；1080宽为540，不把右侧平台安全区实现成暗中左移。安全区通过文字宽度和换行处理。按内容区居中时记录明确区域和中心，仍服从本次要求。双行的每行保持居中，高度按镜头另行选择。对生效ASS运行[字幕坐标检查](../../director/scripts/check_caption_layout.py)，检查画布和锚点；该结果不能代替最终编码的字形、长句、遮挡和手机观看检查。

## 镜头与空间

底部只留几十像素，在编辑器里完整可见，发布后可能被作者、文案、话题、进度条或操作栏遮住。右侧互动按钮也要留空间。平台界面、画幅、文案长度和组件会改变遮挡范围；项目使用的安全区数值标明为排版判断或模拟参考，不冒充三平台通用官方规范。

先核对实际导出画幅、SAR/DAR与当前主版，再按镜头安排字幕。普通口播可从中下部留出底部文案区；大脸近景若挡住嘴，改放上方留白或头发区域，并检查固定标题与人物移动。纸面/PIP讲解可放在内容卡与人物之间或空白列。录屏避开正在演示的按钮、输入框与结果；横屏用实际完整画面判断，不套竖屏坐标或默认裁掉画面。

验收对象包含文字、描边、底板、完整多行与入场运动范围。长句和多行句不能扩展到底部遮挡区或右侧按钮区；断行不拆英文单词、不漏字、不把标点单独甩到下一行。缩到手机观看尺寸仍能读清，字号、行数与停留时间结合实际口播判断。

镜头换成近景、录屏或纸面/PIP时重新判断位置，同一字幕句内保持稳定。先看短段排版预览，发现遮嘴、挡操作或标题相撞就调整，再导出整批；不能把某次修订的28%、52%或70%等数值定为所有视频的默认位置。

## 最终文件验收

对最终编码抽查首、中、尾、最长句、最多行句、镜头切换和位置变化处，并在工作台实际播放检查读字与人物/操作的关系。需要时提供同秒新旧版对照和平台遮挡示意；没有打开平台真实发布预览时，记录为模拟检查。抽帧不等于整条连续声画或人工逐字听校。

仅改位置时复用当前版字幕文字和时码，核对无字幕母版的画幅、帧数、时钟和工程对应关系，从母版重做字幕层，不把新版字幕叠到已有烧录字幕的成片上。保留现有剪切、原声和提示词逐句显示，另存MP4、有效ASS、SRT、母版引用及验收证据。

字幕空间调整核对文字和时间等价，忽略重新断行与排版标签；没有改声音时核对音轨末尾和时间戳，直接复制音轨时可比对编码包摘要。完整解码、帧数、fps、SAR/DAR与最终画面检查各自记录范围，不用视频帧数或存在音轨替代音轨完整性检查。

生效ASS与规范ASS同步更新，继承的旧验收、说明和工程路径移入注明用途的旧版参考，另写新版证据。保留完整逐字稿及提示词复制入口。版本切换与网页回读按[改版交接](workspace.md)执行；旧提交的发布记录仍绑定旧文件。
