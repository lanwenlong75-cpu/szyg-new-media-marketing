# 现场教学与改稿标准

## 课程与页面服务现场

识别已有资料中的受众、时长、目标、讲师顺序和最终成品。信息足够就制作；缺失信息会改变课程内容或完成边界时才提问，同时继续独立部分。

先写清本时段学员要相信什么、学会什么、完成什么。内部形成最小页序，无需为了审阅计划额外打断用户。按现场提问、播放、解释、板书、演示、实操和反馈排序。

| 页面动作 | 用途 |
|---|---|
| 问 | 思考并开口 |
| 看 | 获得样本的感性信息 |
| 算 | 比较时间、成本、产出、投入 |
| 证 | 实际材料支持判断 |
| 揭 | 听完学员后逐项给答案 |
| 教 | 方法、关系、完成标准 |
| 做 | 操作并产出 |
| 收 | 确认一句结论或一份成果 |

一页一个主要动作。删除后教学仍连贯，且没有损失认知、证据、练习或反馈，优先删除；只改一页的任务中不能擅自删整套内容。

## 按课型处理

认知和案例课：具体问题引入，先看真实材料再解释做法。一个扎实案例胜过凑数。新概念给真实例子和边界，避免只有定义。

实操课：先让学员看成品与完成标准，再给最短路径。示范、动手、检查、反馈、修改连成流程。教程细节进备注或操作资料。

板书课：屏幕担当锚点，板书展开过程。备注包含开场问题、板书顺序与箭头、停顿、追问、学员填写项、完成标准和转场。少页不代表缺讲解。页数和时长按本课设计，不固定九页或两天。

共创和汇报：写清任务、产物、负责人和反馈方式。接续已有学员材料。用户要求展示收尾时，以展示、反馈、修改提交收束，不自动追加总结页。

## 逐页设计单

可用 Markdown 或 JSON，屏幕与过程分开：

```json
{
  "id": "stable-page-id",
  "action": "问",
  "title": "谁能独立完成这项工作？",
  "reason": "把目标落到真实岗位任务",
  "core": "按真实交付判断使用深度",
  "layout": "question",
  "screen": ["谁能独立完成这项工作？"],
  "relationships": [],
  "media": [],
  "notes": {
    "opening": "请说一个岗位和一份真实成品。",
    "board": ["岗位", "任务", "谁验收"],
    "pause": "等20秒，请两人回答",
    "follow_up": "结果最后交给谁？",
    "transition": "现在选择一个可以先试的岗位。"
  },
  "sources": [],
  "reveal": []

```

来源追溯到原始文件、链接或用户文字，有时间点时保留。长解释、假设、口径、资料缺口进入备注。

## 事实与案例

- 已核实事实、当事人自述、粗估和课堂判断分别表达。外部视频中的收益默认按其自述。
- 职位、薪资、价格、模型能力、排行等动态内容当前核查，记录日期与原始来源。
- 多类任务不能直接换算全职员工，招聘预算不能写成实际节省，一次演练不能写成长期结果。
- 当前用户的照片与案例按提供的公开范围使用。本分享包不携带私人客户案例、人像库或账号权限。
- 方法名、顺序、人名和主图以本门课最后确认版本为准，不强加别的课程框架。
- 缺原图或来源时留明确待补位，不能捏造证据。

## 修改与版本

1. 先确认实际文件、当前版本、页序和标题。遇未保存编辑或恢复提示先稳定保存，无法确认时避免覆盖。
2. 先修改内容真源，再更新派生成品；已有生成器时复用，防止下次构建覆盖。
3. 删页和移页后按标题、前后页重新定位，核对衔接与备注。
4. 保留可恢复副本，输出清楚的新版本。确认定稿后同步入口；只有明确指令才删除精确旧对象。
5. “丰富一点”先增加真实图像、细节和图解；“单调”先检查全套节奏。
6. 对标作品学习结构和阅读关系，重写自身内容，不照搬竞品文案、价格、权益、人物和成果。

## 验收

### 内容
目标明确；每页动作与存在理由清楚；无重复、自动衍生理论与装饰过渡。用户要求的标题、删改、人物排位、图层与术语落实。备注保留话术、来源、限定、板书和练习步骤。

### 视觉
逐页查看1280×720实际渲染。全套缩略图只辅助节奏检查。最后一排能辨认核心字和主图；截图指定证据不用放大页面即可读。人物无拉伸，裁切正确，箭头对齐且不穿字。画面无页码、重复场次／姓名角标、源码标记和遗留占位符。

### 文件与现场
PPT文字和必要图表可编辑，备注保留；媒体嵌入或随包，字体在目标设备可用。视频可播、暂停、拖动、回放、全屏。PPT原生动画和视频操作需要在演示软件中实际试播。修复后重渲染受影响页。

静态渲染、应用内播放、目标教室投屏分别说明。文件存在与结构检查通过，不自动等于所有设备上的课堂验收。

核心字看不清、图片变形、箭头错位、证据失实、方法被改或媒体不可操作，修复后再交付。
