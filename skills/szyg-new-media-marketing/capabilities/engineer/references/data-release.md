# 数据与发布

按当前产品的实际账号与环境运行。客户端、云函数、云数据库、云存储和管理员身份分别确认；项目名称相近也不能复用其他产品账号。

默认本地测试使用隔离夹具。源码修改、代码迁移和依赖安装不授权覆盖已有云记录；seed、管理员、环境变量和凭据按用户实际授权维护。凭据不得写入知识库、源码、任务回执或命令输出。

分别验收：本地检查、原生编译、微信预览码、手机体验、开发版上传、代码审核、备案与正式发布。报告真实工具回执，保留日期。Git 提交、远程同步和微信发布也是不同动作。

需要外部写入时先完成可审阅的实现与相关检查，再按本轮及已有授权执行具体动作。没有上传或发布授权时交付本地稿和待办；不为搭建员工或验证机制而发布、覆盖云记录、发送消息或更改账号权限。
