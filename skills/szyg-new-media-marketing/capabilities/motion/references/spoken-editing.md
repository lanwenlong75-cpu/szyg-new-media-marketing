# 口播语义删减与波形气口

用于已授权的口播精剪、气口修订、删重录/口误/废话，以及“字幕正确但原声还留了半句”的反馈。沿用本期画面、帧率、标题样式与降噪音轨，另存新版本。本文说的“波形”是音频幅度和时间特征，不是识别说话人身份的“声纹”。

## 最重要的区别

| 要解决的问题 | 判断依据 | 不能替代它的证据 |
|---|---|---|
| 哪一句是重录、废话或多余半句 | 原片实际表达、两次 take 的独立内容、用户定位、必要时语音对齐/听辨 | 整理后的字幕、单次整段 ASR、音量阈值 |
| 切在哪里不伤字头字尾 | 对齐原片的峰值/RMS 包络、VAD、相邻音节与帧时钟 | 整句 SRT、被拉长的 ASR 逐词区间 |
| 呼吸/静音是否过长 | 实际波形空隙、语义停顿、节奏要求 | 每个停顿都机械归零 |
| 成片是否完成 | 最终编码文件的内容复核与技术检查分别成立 | 解码通过、字幕正确、时间变短 |

字幕可以省略口头词，ASR 也可能合并或跳过重说。必须实际删除对应音视频区间，才算清掉有声残留。降噪、句间增益降低、静音压缩均不算语义删减。

## 先确认语义，再修气口

1. 读取原片、当前成片、保留区间和字幕来源映射，确认用户说的版本与时码。接缝附近取前后 2–4 秒；同时核对原片对应区间。检查开场、重录起句、合成句接点、每个主题起句和最后一句。字幕应反映最终真实表达，不能用改字掩盖音频残留。
2. 转写保留未经文案清理的口头词、半句、重复与每次起句。发现重说、词时码跨过停顿、长/短窗口矛盾或两个模型冲突时，把**第一次起句、后一次完整起句、包含两次的窗口**分别截取复核。可用本地 ASR、原声听辨或强制对齐补证。短窗口转写可采用 `vad_filter=False`、`condition_on_previous_text=False`，不提供会诱导其补成预定文案的初始提示。
3. 不因某一模型漏掉重复就判定其他结果是“幻觉/误报”。若用户已听到对应问题，把这当作具体定位证据，继续核对原片；无需让用户重复证明。词边界漂移也不能当作该词一定存在/不存在的证据。仍未确定的片段列为待定位，不得声称“整片废话已清完”。
4. 对已确认的重录，优先选语义完整且接续自然的一次；删除前一次失败 take 的**整个实际片段**及需要收紧的空隙。只有后一次确实缺少必要词时，才拼接两次表达，并独立检查拼接后是否只说了一次。不要把两个起句接在一起后，只在字幕里合成一句。
5. 将每个删减记为 `retake / filler / pause / breath`，记录输入文件/版本、输入时码与帧号、删除的实际表达、保留表达和证据。气口候选不得算进“删除了多少句废话”。模型冲突与待定位项保留状态，不能用总体“检查通过”覆盖它们。

## 波形分析与工具

- [Auto-Editor](https://github.com/WyattBlue/auto-editor)：幅度候选入口。已实测官方 Windows **31.7.2** CLI；该版音频分析按时间桶读取 PCM 最大绝对幅度。2026-10-12 核对开源 CLI 实际 LICENSE 为 Unlicense；程序依赖与其他产品部分分别遵循自己的许可证。版本与帮助以本机实际结果为准，不能把历史 Star/维护日期当当前状态。
- [Silero VAD](https://github.com/snakers4/silero-vad)：辅助保护人声，已通过 faster-whisper 的 ONNX 实测；实际 LICENSE 为 MIT。它也可能把吸气判成人声，或漏掉弱辅音，不能单独决定语义删除。
- [cut-video](https://github.com/louisedesadeleer/cut-video)：可参考分别截取 take、强制对齐与短窗口复核的方法。未运行整套；其默认英语 MFA 与 macOS 命令不能直接当作本机中文方案。不要未经适配就承诺词边界精度。

可复用入口 `scripts/analyze_speech_cuts.py` 使用 Python 标准库和 FFmpeg / FFprobe，提取 16kHz PCM（保持声道），以 **10ms** 桶生成各声道最大 RMS 与全声道峰值；可选调用本机 Auto-Editor 与已安装的 faster-whisper / Silero。输出波形、候选、参数与来源摘要；**不渲染、不改原片、不判断废话、也不把候选标为通过**。选用没有 numpy / faster-whisper 的 Python 时省略 `--vad`，报告会注明缺少人声检测。

```powershell
& '<当前机器实际工具或素材路径>' '../scripts/analyze_speech_cuts.py' `
  --input '本期对齐后的原声视频或PCM完整路径' `
  --output-dir '不存在的新分析目录完整路径' `
  --fps 30 `
  --ffmpeg '<当前机器实际工具或素材路径>' `
  --ffprobe '<当前机器实际工具或素材路径>' `
  --auto-editor '<当前机器实际工具或素材路径>' --vad
```

上述是本机 30fps 工具示例，输入、输出和帧率须填本期值；其他机器重新发现工具。只有音频的输入必须通过 `--fps` 提供目标帧率；视频自动取平均帧率，显式帧率须与输入相同。脚本拒绝平均与标称帧率明显不一致的输入；正式渲染前仍需核验 CFR / 实际帧时钟，VFR 先对齐。音视频起点不一致时先对齐，不把抽取后从零开始的 PCM 时码直接套回未对齐原片。

31.7.2 已测试的原生候选命令：

```text
auto-editor levels input_pcm.wav --timebase 100 --no-cache
auto-editor input_pcm.wav --edit audio:-32dB --margin .08s,.10s --smooth .133s,.10s --frame-rate 30 --export v3 --output candidates.v3
```

这些参数是本次素材的起点。音频输入生成的原生 v3 不自带正确竖屏画面尺寸；提取候选帧区间再应用到本期真实母版。不要直接把其默认画幅当成正式成片。

## 字头字尾保护与音轨

- 在原声 PCM 上判断，避免强降噪把弱音压低后误判为静音。对已有降噪版本做修剪时，复用同源、对齐的降噪 PCM，不在 AAC 上反复叠加模型。保持原声 / 处理后 PCM / 编码文件的时钟与来源记录。
- 本次起点：RMS 低于 -32 dBFS、空隙至少 0.33 秒；内部深静音低于 -40 dBFS 且至少 0.13 秒。普通句内保留约 0.22 秒，话题转场可约 0.28 秒，左右保护约 85 / 105ms、深静音区两边再留 25ms。实际删除中心还核对 RMS 不高于 -36 dBFS、sample peak 不高于 -22 dBFS。**这些不是对所有口播都安全的常数**；弱辅音、刻意停顿、笑声与情绪停顿要按内容保护。
- VAD 与波形只提供切点证据。ASR 词区间覆盖静音时不要照词时码硬切；VAD 覆盖候选时继续检查是呼吸还是轻声，不用阈值自动绕过。保护不足就缩短删减或保留。
- 删减按最终帧时钟量化：起点向上、终点向下取整，视频、音轨与字幕共用同一组保留区间。48kHz / 30fps 时每帧 1600 samples；其他帧率用有理数计算，不能沿用 1600。未删帧的声画内容不可相对移动。
- 句间低音量区域可轻压呼吸（本次 -3 至 -7 dB、25ms 余弦渐变）；新接点只在确认的静音把柄内做短淡化（本次 15ms）。字头字尾不能被 fade / crossfade 盖掉；保留自然换气，别把波形压成全零。完全静音没有有限 dB 值，报告 `null / silence`，不编造极低分贝。

## 时间线、校对台与交付检查

1. 先完成语义删减，再映射新时码 SRT/ASS；被删半句的字幕去掉，完整重说独立显示。保存原片 → 当前输入 → 新版的来源映射。仅文本正确、不对应真实保留语音的字幕不能验收。
2. 输出新压字成片、无字母版、独立 SRT/ASS、编辑页和删减决策。保留旧版可 A/B，按对应内容跳转而非生硬使用相同新旧秒数。入口、下载、重渲染脚本、参数、播放器与标明版本的文件一起更新；备份旧入口。
3. 字幕条数未变时保持 localStorage 文字记录并换新时码；删/合并字幕后按来源 ID 显式迁移，使用新版本键，保留旧记录。不能强按数组位置导致整段改字错位；“恢复交付字幕”后也不能又自动导入旧修改。
4. 内容复核覆盖所有保留场景、合成句、主题起句与片尾；对本轮删重录的开头，同时检查**第一次片段、后一次完整片段和最终编码文件**。最终开头只出现一次完整表达，才关闭这个重录问题。开场检查不是靠 SRT 搜不到重复。
5. 技术单独检查实际帧数/CFR、SAR/DAR、音视频时长、完整解码、最终编码后响度/true peak与波形偏移。页面检查新默认视频、时码跳转、SRT 下载、文字保存/迁移和旧新对应跳转。技术通过不等于主观听感或全部语义检查通过。
6. 有音频听辨能力时听最终文件的接点与完整内容；没有时明确实际范围，结合原片片段、未经清理的独立转写与帧/波形证据推进，不称“逐字听校”。交付报告将 `semanticReview`、`boundaryReview`、`technicalReview`、`humanListeningChecked` 和 `unresolvedItems` 分开；未解决项不写进“全片已剪干净”。

## 这次漏剪的反例与纠正

2026-10-12 AI语法第三集：原片第一次是「当你学习」的半句，后一次是完整「当你想学习一个陌生领域」。旧工程误把第一次起句与后一次连接，字幕却只呈现一次。长/短窗口有时合并转写，我又把识别到两次的结果误判成模型误报；静音处理只缩短了两次之间的空隙，没有删除有声半句。

用户定位后，分别截取两次起句，small 和 medium 都在第一片段识别到「当你学习」、在后片段识别到完整重说；两模型在旧成片开头也识别到两次。最终删除旧 v2 约 3.667–4.867 秒（36 帧 / 1.20 秒），保留完整后一次；第三集 48.60 → 47.40 秒、1458 → 1422 帧，字幕 26 → 25 条，旧改字按来源合并迁移。最终编码开头两模型仅识别到一次完整起句，完整解码、音画对齐和网页检查通过；**没有人工听校**。
