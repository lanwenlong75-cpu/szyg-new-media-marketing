# 已有口播降噪与对比交付

适用于录音背景噪声、已有成片换降噪音轨，以及用户反馈前一版不明显。先沿用既有剪辑，找到未降噪的原声 PCM 或原声母版；避免在已强降噪的成片上反复叠加算法。有人声、配乐、音效分轨时优先只处理人声，保留其他轨；混合成片须检查模型是否误削弱背景音乐或其他必要声音。

用户同时要求去气口、重录或废话时，另读[口播语义删减与波形气口](spoken-editing.md)。这会改变时间线：字幕、画面和音轨须同步映射；不能套用本页“时间线保持”的验收，也不能把降噪成功当作语义清理成功。

## 已实测的项目与选型

- [DeepFilterNet](https://github.com/Rikorose/DeepFilterNet)：本地 Windows 已实测官方 [v0.5.6 发布包](https://github.com/Rikorose/DeepFilterNet/releases/tag/v0.5.6)，无需安装 Torch。该发布包的实际运行日志显示模型为 **DeepFilterNet3**；程序版本和模型名称分别记录，不凭旧 README 推断模型。使用其他发布版本或平台时先看实际 CLI `--help` 和运行日志。
- [ClearerVoice-Studio](https://github.com/modelscope/ClearerVoice-Studio) 与 [Resemble Enhance](https://github.com/resemble-ai/resemble-enhance)：2026-10-10 查阅过官方仓库，未实测。需要换算法时再核对当前依赖、平台与模型，不能称为已验证方案；Star 不代表本期声音效果。

用户明确要求 GitHub 调研时核对官方仓库和 release 的现状，再实际运行选定项目。优先复用可执行的本地程序，不把大型 Python/GPU 环境安装作为必经步骤。不要把 2026-10-10 的调研结论当永久最新状态。

## 参数与可复用入口

本次较强降噪的起点：`-D --pf --pf-beta 0.06 --atten-lim-db 100 --reduce-mask 2`。

- `-D` 补偿 STFT / 模型前瞻延迟；仍需检查原声与处理后说话波形的时间偏移，避免重复补偿。
- v0.5.6 的 `--pf-beta` 默认 0.02，0.06 是本次较强后滤波起点。轻声、尾字或音色受损时减弱后滤波或降低衰减上限，用同一段原声重新生成。
- `--atten-lim-db 100` 代表允许完整降噪，0 代表不降噪，并非“固定降低 100 dB”。双声道的 `--reduce-mask 2` 为平均掩码；单声道可用 `--channels 1`。

`scripts/denoise_voice.py` 使用 Python 标准库、FFmpeg、FFprobe 和已准备好的 DeepFilterNet CLI，输出 48 kHz PCM、AAC 音轨、模型日志与参数报告。拒绝复用已存在的输出目录，保留失败日志以便排查。它只处理音轨，不修改画面、字幕或原工程，也不宣称完成主观验收。

Windows 当前实测工具路径如下，换机器时重新发现，不要求用户使用这些固定目录：

```powershell
& '<当前机器实际工具或素材路径>' '../scripts/denoise_voice.py' `
  --input '本期未降噪的剪辑PCM或原声视频绝对路径' `
  --output-dir '不存在的新工程音频目录绝对路径' `
  --deep-filter '<当前机器实际工具或素材路径>' `
  --ffmpeg '<当前机器实际工具或素材路径>' `
  --ffprobe '<当前机器实际工具或素材路径>'
```

示例中的两个素材/输出路径须替换为本期真实路径。`--preview-seconds 10` 只生成开头短样，报告明确记录；正式交付不带该参数。I=-16 LUFS、TP=-1.5 dBTP 是此人声修复入口的可调起点，最终编码后复测；保留本期已约定响度时用 `--loudness` / `--true-peak` 修改。

## 替换声音与验收

1. 解码原声到 48 kHz PCM，再运行模型。处理时保留整条时间轴，不按 VAD 删除静音或重排语句。模型延迟补偿可能令末尾少几十毫秒；复用脚本在模型输入尾部预加 0.1 秒静音，再裁回原片长度，减少原有尾字被截掉的风险。时长差超出 0.1 秒则停止，仍须核对最后一句和实际说话波形，不能把事后补零当作找回尾字。
2. 根据目标影片的真实时长/帧数设置 PCM 长度；可用 `--duration-seconds` 明确传入目标时长。对最终母版和压字版复用同一条 AAC，使用 FFmpeg `-map 0:v:0 -map 1:a:0 -c copy` 封装为新文件；明确映射其他确需保留的轨道。保留原分辨率、帧率、章节顺序、SRT/ASS 与画面时间。检查原音频流起点；有非零起点的素材先对齐，不能直接按零起点替换。
3. 检查最终文件音视频时长、实际帧数、完整解码、编码后响度与 true peak。画面无需变动时可比较复制的视频包摘要；抽查开头、中段、接缝、片尾人声波形偏移。音轨技术处理完成不等于听感提升。
4. 在原声和新版本间截取相同区间，统一到相近响度后比较**说话期间**的噪声、轻声、词尾和音色。用户反馈前一版不足时提供“原声 / 上一版 / 本次”三版；片段按本期内容选，包含重要结尾，不照搬某次健身房视频的主题或时码。
5. 没有实际音频听取能力时明确验收范围，可用本地 ASR 抽检辅助判断语句是否仍可识别，但不把识别结果写回已校对字幕，也不称为人工听校。不能以停顿窗口变安静证明讲话时噪声已明显改善。数字零没有有限 dB 值，不把 `log(epsilon)` 的计算下限报告为几百分贝的真实降噪。
6. 同步更新校对页默认视频、下载链接、字幕重渲染脚本输入和交付校验清单，先备份旧入口。沿用字幕 localStorage 键和已保存编辑；提供版本清晰的新视频/试听链接，避免旧标签页继续播放旧文件。验证页面加载、切换时保留播放位置、字幕数和试听互斥播放。

## 本地实测依据

2026-10-10 健身房 AI 赋能项目使用上述 DeepFilterNet3 参数从原声处理全片 379.133 秒；11374 帧画面保持、8 段说话波形抽检偏移为 0 毫秒，两版完整解码通过，编码后 -16.19 LUFS / -1.43 dBTP。提供四段三版本试听、约79秒机器识别抽检和可编辑字幕校对页。用户随后表示“ok”并要求保存到 skill；该次反馈不推广为所有素材的质量保证。

原始参数、运行日志和成片证据位于 `本机私有历史依据未分发；不作为运行依赖`、`交付_v7_DeepFilterNet`；公开给本用户的试听与网页验收位于 `本机私有历史依据未分发；不作为运行依赖`。这些是本机案例指针，不是其他机器运行所需素材。
