# 客户分析

## 从业务问题选样本

先明确分析服务于获客、首次咨询、会员服务、复购还是具体项目。购买标签是历史购买层级，当前需求、关系状态和适合的下一步另行判断。

群体分析按用户口径重新取样，读全部入选客户的完整记录，记录人数、层级重叠、缺失资料和观察区间。只有已成交样本时可以分析已购客户的共同表现，不能计算全体粉丝转化率，也不能证明这些表现造成了成交。

单客分析只围绕这个人的真实记录，不把同名客户、行业常见问题或备注中的行业当作其亲口描述。跨客户归纳需指出哪些人支持、哪些人不支持、还有哪些未知。

## 建立客户证据卡

从原文提取会影响本次行动的信息：

| 维度 | 要回答的问题 |
|---|---|
| 身份与业务 | 客户明确说自己做什么、为谁服务；职位、决策权与规模哪些未知 |
| 当前任务 | 他现在想解决哪件具体事情，是什么场景或事件触发咨询 |
| 已有做法 | 已经尝试什么、在哪一步卡住、有何可使用的材料或约束 |
| 需求与代价 | 他明确表达的困难、目标和紧迫性是什么；不靠行业标签猜预算 |
| 沟通过程 | 客户提问、我方回应、补资料、购买、服务各发生在什么时间 |
| 购买事实 | 哪种标签或交易证据、什么产品；实际金额和日期是否明确 |
| 阻力与反馈 | 原文是困惑、时间限制、价格顾虑、信任问题还是产品不适配；没有说清就保持假设 |
| 当前状态 | 最新一轮在等谁、对方最后问了什么、已有承诺是否完成 |

不为把表填满编内容。正文缺语音时，把可能影响结论的缺口写出来。

## 做出可用判断

从“明确需求—适配依据—尚缺信息—下一步”连接结论。比较可行路径：继续澄清、给示例或小范围验证、完成已有服务、推荐合适产品、暂缓跟进。每个建议指出对应的证据与选择条件。

低价会员购买可以证明该层购买关系，不能证明客户已购买企业方案、具有企业预算或希望升级。复购机会只有需求、使用反馈和下一层价值能接上时才列为候选，不直接写成“高意向”。

对“购买触发点”先找客户明确描述，缺少时写候选解释，列出对话中的时间顺序及其他可能。销售话术发出与付款先后相邻不能单独证明因果。

群体报告避免堆行业名单：说明最有用的共性、样本分布、差异和下一轮可验证的问题。少量样本用人数与实例，不给没有依据的精确画像比例或收益预测。

## 输出与验收

简单单客问题给结论、证据和能执行的下一步即可。较大任务可使用技能内的客户分析模板，附每人的原始入口、事实/推断/未知、行动建议及不适合该建议的条件。

最后核对：样本依据正确；同一人未重复计数；来源与日期未误作成交；我方说法未变成客户需求；行动能解决当前问题；未把缺失记录或小样本结论包装成确定事实。
