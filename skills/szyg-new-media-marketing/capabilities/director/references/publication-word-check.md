# 发布用词检查

剪辑、封面、字幕、模型和发布准备时使用。先读当前项目`.agents/publish-word-policy.json`，只采用与实际项目和IP匹配的偏好；没有配置时使用共用语境检查种子，不继承另一个IP的微信→VX等显示替换。

## 词库与处理

词库分为用户指定的可见用词替换，以及来自平台规则的语境检查线索。每项记录平台、动作、依据类型、核验时间和来源。共用种子是检查线索，不能声称是平台完整禁词表或命中即违法；正常品牌提及、操作教学、排序等不能机械屏蔽。原声是否处理按用户当前选择，未经授权不消音。别名和同音字不能让违规营销、虚假承诺等行为变合规，应修改实际内容。

为当前版本建立显式检查清单，surfaces至少覆盖captions、graphics、cover、title、publish_copy，并另列speech。每项包含id、kind、path、format；无此表面写status=not_present及reason，尚未取得的发布文案留空并说明。支持ass、captions、models、text；不递归扫描原片档案、历史版本和工程路径等非发布证据。截图、封面像素、录屏不能只凭文本扫描就记已查，须核对最终图像及实际范围。

```text
python <本能力目录>/scripts/content_word_check.py scan --root <项目根目录> --entity <当前IP> --manifest <本版清单.json> --output <本版检查.json>
python <本能力目录>/scripts/content_word_check.py transform --root <项目根目录> --entity <当前IP> --input <当前字幕.ass> --format ass --output <新版本字幕.ass>
```

scan只读，退出0表示所列文本表面完整且无命中，2表示有未处理替换、语境项或未检查表面；两者均不等于平台审核。报告绑定词库和检查文件SHA256。transform只执行本对象明确的replace规则，拒绝覆盖输入或已有交付，不自动改写review项；长词优先，ASS格式标签不替换，caption JSON只改displayText，保留text/原声证据。修改模型或图片文字时在实际生成源改后重绘，不能仅改工程说明。

## 交付和发布前复核

先检查实际输入，另存字幕与替换记录，复扫后从正确无字幕母版导出；复查替换处的手机尺寸、居中和实际字形，确认时钟与其他图形未变。根据本次音频选择检查音轨；原声保留时复制音轨并保留真实口播逐字稿，显示字幕另供下载。保留旧版、原始资料、平台来源及原话，不全库搜索替换。

用户指定了发布前检查时，新的字幕、图形或发布文案会使旧报告失效，按当前文件重新检查；不将旧记录套到新payload。上下文命中逐条写明保留、实质改写或待核对的原因，未经实际核对不记已解决。检查与改字不授权发布，旧发布与定时任务继续绑定原提交。
