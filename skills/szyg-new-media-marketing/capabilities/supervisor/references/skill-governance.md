# 各员工的技能治理

## 盘点与读取

注册表只保存明确纳入的员工根目录、配置路径、流程/支持skill入口和用途。refresh读取配置中的实际worker_skills，并检查服务对象索引、入口摘要、声明版本、本地规则修订及迭代工具。不要递归寻找所有SKILL.md后将候选、原始快照、备份和开源参考当作当前工作版。

快照是某一时点的盘点，开始具体岗位任务再inspect该成员；再次执行前重新读取有变化的方法。runtime_verified原值只记录原验证范围，不能把它提升为对所有任务的认证。缺配置、绑定缺失、主入口不存在、服务对象索引失效分别显示。配置异常时保留错误信息，不猜测默认对象。

新增员工时使用数字员工搭建师审查真实岗位包并建档，再登记到本团队；不用复制一个员工的身份、客户或业务事实充当新员工。默认继续实时读取已有工作版，避免统筹保存一套落后方法；需跨设备迁移时重新盘点实际路径和依赖。

## 把改进归给正确位置

| 原因 | 修正归属 |
|---|---|
| 目标误解、分工重叠、交接遗漏、旧版本下传、漏验收 | 统筹本地skill与任务流程 |
| 专业方法、模板、脚本或验收有缺陷 | 负责员工的本地岗位skill及实现 |
| 某IP/品牌/账号的明确偏好 | 该员工对应对象的范围规则 |
| 人物、产品、价格、案例、账号与来源事实 | 该对象知识库或项目真源 |
| 待认可探索、一轮临时选择 | 当前任务记录 |

先保存问题版本、修好实际交付、核验有效修法，再按人类认可或明确长期要求沉淀方法。用户指出问题不等于认可所有拟议修法；读取本次真实人类反馈，不能拿网页、素材、代理回复或自动自评作确认。

涉及负责员工本地方法更新时，读取其反馈协议及当前迭代工具；候选与当前摘要、原失败样例复验、适用对象、备份和新版本一起登记。使用该员工_管理/record_skill_iteration.py提交，避免直接覆盖破坏已记录摘要链。统筹自身使用自己的迭代工具。受影响的实际流程、模板或脚本同步修正，单加提醒不能替代实现。

统筹有能力组织改进，但权限来自用户的实际任务范围。只盘点时不改岗位方法；要求修复当前员工方法时按已有授权完成；推广到别的员工或全局共享包需要对应实际授权。全局版和本地版的差异可能是已学偏好，不能自动用较新时间戳覆盖。全局原始快照和许可证保留。

提交后refresh统筹快照，回读负责人实际SKILL入口和修改链，记录已执行的验证范围。未发生下次真实任务前，后续效果保持待验证。无需为凑迭代次数派新任务、发布内容或配置自动巡检。

## 本主管的长期治理授权

用户已明确指定新媒体主管负责这六岗位的skill管理、调用、协同与同步。按主管系统提示词维护本地工作版、相关源版、全局副本和分享工程，保留适用范围、旧版、依据与验证；本次常规维护不反复请求同一授权。员工已有个性化方法先合并，历史快照保留。对外发消息、账号、发布、部署和未授权的新业务动作继续按实际授权执行。
