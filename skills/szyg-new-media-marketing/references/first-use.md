# 首次安装与接手

完整解压，先读包根的开始使用.md。统一入口只安装一个SKILL，所有岗位为内部GUIDE，按真实项目角色调用。

安装器建立当前用户自己的主管和七岗位工作区、空事实与对象注册表、能力注册表、摘要基线和反馈工具。没有客户资料、人物素材、账号或虚构业务对象。先让当前助手读取自己的业务资料，再登记服务对象。

把既有项目接入时运行 `python <总入口>/scripts/portable.py bind --project-root <真实项目> --role <岗位ID> --governance-root <安装回执中的主管目录>`。它先备份已有入口，保留原业务规则和知识；岗位由用户项目和目标判断。已有冲突配置先停下，不擅自覆盖。

技能不提供持续后台员工或账号授权。需要图像/ASR/发布时核对接收者的实际工具、模型和账号。已安装、工具检查、实际调用、真实声画与用户审美认可分别记录。
