# 编导思维与观众可用性

适用于口播、教学、演示和产品介绍的画面策划与修订。编导要把口播的意义转成观众此刻需要的画面，让观众理解内容、判断依据，并能照着使用。每段素材、文字和动效都有明确的表达作用。当前用户的内容、风格、时长与展示要求优先；不因此重写观点、套固定宣传结构或改变已授权的工作范围。

新文案或风格转向先读[文案选型与协作](../../director/references/copy-style-collaboration.md)，按表达任务、真实素材和当前项目的样片偏好确定路线。现有模板与显式版本继续保留；局部修正不重新选风格。

## 剪前：先决定观众要看到什么

先读完整口播和本期素材，确定受众、核心问题及看完后希望观众做的事。输入已有答案就直接制作；只对影响实际成品的缺项澄清。

在现有分镜、brief 或剪辑决策中，逐个有意义的段落记录：时间范围、内容依据、观众需要理解或使用的信息、对应画面/素材、展示与停留安排。简单修改只补相应段落，不强制另建复杂文档。

| 口播在讲什么 | 观众此刻需要什么 | 对应画面 |
|---|---|---|
| 提示词、指令、可照抄文案 | 跟随讲解逐句理解，讲完能拿走使用 | 当前句随口播出现；完整字稿另供复制；明确可替换信息 |
| 操作方法 | 知道在哪里做、怎么做、做完是什么 | 对应界面、操作目标、步骤及结果 |
| 案例、效果或对比 | 看见支撑结论的材料与差异 | 本期真实案例、结果或前后对照；必要示意明确标注 |
| 产品、课程、知识库等交付物 | 知道里面有什么、对自己有什么用 | 实际产品图、目录或演示，定位到正在介绍的内容 |
| 核心观点、过渡、情绪与行动邀请 | 理解主张、跟上转折和行动 | 真人及简洁重点；按内容需要选择辅助画面 |

先检索本期可复用素材并核对原文件，再安排展示。仅有目录截图时只能据此展示目录，不能把截图列出的文档视为已收到正文。素材不足时利用已有资料完成能成立的部分，并标明具体缺项；示意画面不能冒充实际结果。

## 提示词：说一句、显示一句，保持观众期待

- 从实际保留口播、用户原文或对应素材提取完整提示词。核对角色、任务、输入信息、条件、否定、步骤和输出要求。可以补标点、分段与占位括号；不把省略条件的摘要当完整提示词。若另做优化版本，应与原示例明确区分。
- **默认像字幕一样逐句替换：说到哪一句，才显示哪一句。** 讲解开始不先铺满完整提示词；未讲到的后文、步骤和答案保持不可见，也不能用灰字、半透明、背景截图或预排全文提前露出。画面随口播推进，让观众继续期待下一句。
- 在现有分镜、brief 或展示时间线中记录每句完整文字、开始/结束时间和口播依据。时间来自实际保留口播及核对过的字幕；字幕一条含多句时，要核对真实分句时刻，不按字符数均分、不套固定秒数。讲下一句时替换上一句；仅用户明确要求时才保留已讲过的句子逐句累积，仍不预露后文。
- 每句保留原示例的完整意思和条件，按语义断行；长句可分成随口播出现的完整短句，不能压缩成几个关键词。所有逐句文字按原顺序覆盖完整提示词。排版或模板只能显示整张静态全文时，应改成逐句内容层或逐句画面，不能直接套用提前展示全文的模板。
- 在实际手机/目标观看尺寸检查字号、对比、断行和停留。时间根据本期文字量、信息复杂度及口播安排决定；读不完就调整展示时段、版式或分页，不把某一次视频的字号和秒数作为通用常数。
- 明确行业、产品名等哪些内容需要观众替换。人物、标题、字幕和装饰避开当前句；需要时缩小人物、调整字幕区或隐藏重复标题，让正在讲的内容清楚可读。
- 逐句展示写进实际导出视频。独立交付完整可编辑文本；有校对/预览页时提供查看、复制或下载入口。完整交付不等于讲解开始就展示全文。用户要求视频内可截图的全文时，把完整整理卡放在全部讲完之后，另留合理阅读时间；不要擅自延长用户限定时长。
- 无口播字幕母版与重渲染入口沿用同一逐句展示时钟；仅去掉字幕不能恢复为提前露出全文的内容卡。

## 操作、产品与动效：引导观众看对地方

- 讲操作时，画面对应当前步骤、目标控件与操作结果。重要条件、输入与失败后的区别应能从画面和口播中看懂；不靠一张无关界面截图解释整个过程。
- 讲产品时，展示本期实际产品素材，说明正在介绍的内容与用途。目录图可以用关键帧平移、缩放、停留或标注，让观众看清相应板块；长图需要检查裁切范围、阅读速度和关键内容是否真正出现。
- 原片中的举例、论证、操作条件和结论按用户目标保留。删重录、废话和气口时，按[口播语义删减流程](spoken-editing.md)处理；不要因为节奏快而剪掉观众理解或照做所必需的信息。
- 选择画面和转场依据口播的语义节点，衔接观点、示例、结果与行动。人物是表达与信任线索，资料是理解与使用线索；二者比例按当前段落安排，不强制全片一个圆窗或一种版式。
- 阅读卡可以稳定停留。动画用于引导注意、展示变化或解释关系；不能让正文在阅读中不断跳动，也不为了制造变化切掉尚未读完的内容。调整时间时仍遵守真人声画时钟和模板动作保护窗，不冻结真人口型或拉伸整片来补时间。
- 只改视觉展示时，沿用已核查的剪切与声音，另存版本；有声画或语义问题仍单独记录，不能用更完整的字幕/内容卡掩盖它。

## 导出后的编导验收

对实际导出的最终编码视频检查，记录在现有验收报告中：

1. **对应**：每个重要讲解都有合适的视觉支持；素材、数字、条件和当前口播一致，关键展示时段准确。
2. **完整**：按顺序汇总视频中每句文字，逐项对照完整来源及可复制字稿，检查遗漏、裁切、遮挡。否定、条件和占位信息仍完整。
3. **可读**：按实际观看尺寸抽查最长文字与关键帧，字体清楚、断行自然，字幕和人物不挡正文；稳定状态可暂停截图。
4. **节奏与期待**：连续播放整个提示词段，逐个检查句子切换点前、中、后：当前句随口播出现、未讲到的后文不可见、上一句按展示模式退出、无闪现全文。检查阅读时间、关键帧速度及人物口型。静帧检查不能证明逐句同步或连续观看时来得及读完。
5. **可用**：观众能够替换自己的信息、找到操作入口或看懂产品内容；视频、完整文本、复制/下载入口一致，当前页面与重渲染入口使用正确版本。

分别记录内容覆盖、逐句时间线与提前露出检查、静态排版、连续观看、音频听校和技术检查的实际范围。缺少某项检查就保持其未检查状态；完整解码通过不能代替逐句同步、可读性或人工听校。明确的提前露出、提示词缺漏、遮挡或来不及读完应先修正，再交付该展示版本。

## 本次规则的来源与适用边界

2026-10-13 用户强调提示词要完整可用；2026-10-14 又明确指出 AI获客文案的全文提前露出会降低期待，要求“像字幕一样，出一句显示一句”，并记住、更新 Skill。本次修订替换旧的“讲解时全文同时可见”默认规则：完整性通过逐句完整覆盖和可复制字稿保留，视频展示按口播逐句推进。

这是当前用户的默认编导偏好。可分发 Skill 以逐句展示为默认，并服从使用者本次明确指定的展示方式；不把此偏好强加给需要静态文档阅读或明确要求同时展示全文的任务。规则更新不代表历史 v4 成片已经重剪或通过逐句验收。
