# 新原片先接收命名，再剪辑

先读当前工作区 AGENTS 与 `.agents/source-intake.json`。已配置接收入口时，在新素材剪辑前执行该项目入口，核对编号、实际路径与原片摘要，再进入转写、语义精剪、模型设计、导出、全文字幕封面和观看交付。用户只需放文件，不要求其先建日期文件夹或手动改名。无此配置的项目按自己的原片规则处理。

当前视频库由用户明确指定为扁平投放：待剪素材根目录只保留原片文件，文件名使用内容编号＋原片序号＋真实扩展名；主题在台账中维护。该目录包含已剪原片，剪辑状态由登记决定，不能重复剪。工作区的原片接收脚本以SHA-256和既有编号识别，不用文件名猜内容，也不重新编号已规范原片。

接收迁移应先保存旧名/旧路径/摘要与计划；不改字节、不覆盖冲突文件；更新当前工程、工作引用、原片全文与台账播放入口，原始证据和快照保留原样。对既有资料检查路径、内容编号、大小/修改时间与摘要。相同摘要重复投放、目标重名或已登记文件被替换时，保留文件并核对，不强行覆盖或删掉。

规则、登记和脚本放在工作区管理目录；原片投放目录不混入日志或新文件夹。重跑接收应保持原名、编号和字节。接收是剪辑任务开始时的动作；只读台账刷新保持只读，未明确配置后台监听时不声称文件刚放入就会自动运行。

跨IP仍按本次服务对象与登记归属处理；目录规范不授权发布，不改变别的项目的目录或风格。
