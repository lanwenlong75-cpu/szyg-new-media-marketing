# 资料采集与岗位分工

获取、去重、转写、记录来源与整理素材由新媒体运营的内置工具承担；短视频判断、账号风格和文章编辑由当前负责岗位完成。用户只给分析任务时不扩成整号下载，已有全文优先复用。

单条链接读[单条采集](../capabilities/source-archive/single/GUIDE.md)；明确要求整号或批量时读[整号采集](../capabilities/source-archive/account/GUIDE.md)。运行时准备见[当前项目接入](../capabilities/source-archive/account/references/portable-setup.md)。这两个方法及完整运行时随本岗位提供，不独立安装。

先读本次项目AGENTS与资料位置，保存平台ID、原媒体摘要、全文和获取状态。链接不是切换知识库的授权；没有目标知识库时留在当前任务来源目录。正式知识晋升、账号动作、付费获取和新增下载按本次实际授权，缺条件时明确说明；不从标题猜完整内容。
