# 视频内容与发布台账

在用户管理的视频库维护可回读的总表：收过什么、剪到哪里、哪些已发、哪些定时、哪些还没发。编导选片、安排系列和交付前先查表，避免把历史版本当作新内容或重复安排同一平台。

## 一个内容编号，多个版本与发布尝试

- 主表每条内容一行，稳定 `id`，记录主题、系列、拍摄来源、原片路径、工程、当前交付主版、校对页、剪辑状态、待确认事项。
- 无字幕母版、不同画幅、降噪版本、重录修订和历史试剪归在同一内容编号下。完整课程不自动拆条；同一原片真正拆成不同主题时才新增编号，并注明来源区间。
- 发布明细按内容、平台、账号、任务编号、作品编号逐次记录。保存提交时间、定时安排、实际发布时间（有证据才填）、提交的具体文件与摘要、标题、结果、链接、回读时间和证据路径。失败与后续成功的重试都保留，总表不把重试当成多条内容。
- 剪辑与发布分别记录：原片在“待剪素材”不意味着没剪；“已交付”不意味着已发布。收到附件和交付新版时，不改变已提交的旧版本绑定。

## 状态证据

`已发布`需要正式成功回执、作品公开页或用户明确确认。上传成功、任务集合 `allsuccessful`、预检通过不能代替任务详情的实际阶段。`scheduled`是定时安排；到点仍未取得成功结果则显示“到点待核验”，不能按时钟自动宣称已发。`review`显示审核中，失败显示具体原因。历史确认与当前回执冲突时保留两份证据并展示冲突。

缺记录默认“未查到发布记录”。只有用户确认全部通过当前发布系统、且查询完整覆盖任务列表和详情时，才可将缺记录的内容列为“未发布”。账号范围、查询截断或失败都要保留在刷新结果里，不隐去待确认。没有实际发布时间时留空，任务创建时间只标“提交时间”。界面和 Excel 日期均显示视频库约定的时区；本用户为北京时间。

## 本地文件与入口

使用用户既有根目录；本用户为 `本机私有历史依据未分发；不作为运行依赖`，原片入口为 `待剪素材`，不重新创建旧“待剪辑视频”。数据和表格存入 `发布管理`：

- `内容登记.json`：稳定内容编号与工程、来源、主版的持久登记。
- `任务来源.json`：发布任务与内容、提交版本的映射。
- `发布记录.json`：追加的只读回读快照；`人工补充.json`：用户补充或其他渠道证据。
- `视频台账.json`、`index.html`、`视频总表.csv`：由上述记录生成的统一视图；Excel导出为 `视频发布台账.xlsx`。

持久资料不以浏览器缓存为唯一真源。先把用户改过的 Excel/CSV 补充按稳定编号回填登记，再刷新，避免覆盖人工修改。界面保持以主题、状态、日期和待处理为主，路径和任务ID放在展开详情/证据列中。

跨平台命令（Windows用有效Python实际路径，不能假定商店的 `python.exe` 别名可执行）：

```text
python <SKILL_DIR>/scripts/publication_ledger.py --root <视频库> refresh
python <SKILL_DIR>/scripts/publication_ledger.py --root <视频库> register --file <一条内容登记.json>
python <SKILL_DIR>/scripts/publication_ledger.py --root <视频库> record --file <一条发布补充.json>
python <SKILL_DIR>/scripts/publication_ledger.py --root <视频库> sync-yxer
```

`refresh`仅扫描、探测媒体参数并生成视图，不改媒体。新原片/交付叶目录发现后先记“主题/版本待确认”，助手再从完整台词、剪辑决策和交付记录补齐归属，不以文件名自动确认主版本。`register`按 `id`更新，修改前保存快照。`record`只登记证据，不发布。补充记录至少包含 `videoId/platform/account/status/source/checkedAt`；定时还需 `plannedAt`，已发布还需 `publishId/url/confirmation`之一。

`sync-yxer`只调用 `yxer query records` 与 `yxer query details`，不能用它代替正式发布；使用前加载已安装蚁小二 skill 的查询协议和环境检查。没有该服务时保留离线视图并说明未刷新。查询不全时保留已有成功回执，缺记录不标未发。新增发布标题须先登记在对应内容的 `publishTitles` 或按真实任务编号关联，未关联任务在表中单列待处理。

网页模板为 `assets/publication-ledger.html`。Excel用当前宿主的表格工具从同一 `视频台账.json` 导出；本用户已有 `发布管理/生成工具/export_ledger.mjs` 与刷新入口。依赖不存在时交付可用的网页/CSV并说明 Excel 未更新，不能报全部成功。

用户想快捷观看未发布的视频时，同步生成 `未发布观看.html`，模板为 `assets/unpublished-watch.html`。默认使用登记的当前交付主版，无成片时播放实际存在的原片并明确标记；编号、主题、播放版本、剪辑状态与待确认事项随播放器显示。先读交付说明/校对页配置核对主版，不能只按最大版本号选择文件。列表带缩略图，支持换片、倍速与按当前播放时间记修改位置；修改要求包含稳定编号、观看文件、时间与工程，通过复制到聊天或下载交给助手，不能把浏览器草稿当作已收到的正式修改指令。无需用户重新提供表内已有的工程与文件。

本用户也可双击 `发布管理/查看未发布视频.cmd`，启动只绑定本机的观看服务；地址为 `http://127.0.0.1:8782/发布管理/未发布观看.html`。服务只读取名单内的视频和封面，支持按播放时间读取，不提供发布、修改文件或上传接口。总表的观看入口从内容登记的 `watchUrl`读取；其他用户可使用相对文件入口。重启电脑后需重新启动观看服务。

## 每次任务的收尾

1. 收到新原片：按视频库约定保存，登记来源；可复用素材仍按素材库工具登记，不把参考片当本账号待发布内容。
2. 剪辑交付或改版：核对主版文件实际存在、参数及工程说明，更新主版、校对入口与实际验收范围；原片、旧版和已提交发布文件保持稳定路径。
3. 用户授权正式发布/定时后：记录实际提交版本与任务编号，并只读回读各平台结果；更新同一条内容的平台状态。管理台账不代表获得新的发布或改期授权。
4. 返回之前：刷新网页与表格、核对主表和明细数量、时间与版本；点开筛选、成片/校对入口，展示用户能直接查看的表。
