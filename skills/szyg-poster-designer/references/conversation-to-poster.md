# 从多轮沟通到海报定稿

适用于口述材料多、信息密度高，或已经经过多轮反馈的课程、产品、活动海报。已有明确文案和版式时直接执行相关部分；一个局部改字不重跑完整流程。

## 先判断当前要解决哪件事

用户要整理原话时，先归并内容，保持其原意；用户要做海报时再进行传播层级和视觉转化。不要在整理阶段主动加入未定卖点、人物、作品数量或效果承诺。已有答案不再问，未知但不影响当前制作的事项先保留待补。

从当前对象资料和对话中补齐[设计简报](../assets/templates/poster-brief.md)，由助手填写。简报与分区骨架是内部执行依据，可用几句话说明关键判断后直接推进，不要求用户逐项确认或手填表格。只对确实阻碍执行、无法合理判断的事实或冲突提问。

## 把口述内容转成两种颗粒度

- 保留详细原文与教学/产品资料，作为内容来源。
- 海报按当前用途组织成短主题与必要说明，保留关键条件，减少解释性细节。不能把完整口述原样塞进图，也不能只剩空洞标题。
- 用户已经选定的主题、每组点数与细节程度记录为当前文案结构；后续保持同一粒度。先确定结构，再汇总需要检查的文字清单。
- 对“能带走什么”，分开记录计划实操、明确提供的资料、已经存在的文件与尚待制作的内容，不将清单当现成资料。

## 关键词先形成关系

多个关键词看似相关时，先判断各自作用：是场景、资料依据、方法、判断标准、执行岗位还是结果。根据实际内容找出连接关系，或判断它们确实应该独立展示；不为了凑数编造因果链。

先能用一句话解释关系，再安排标题、图示、连接或分区。用户说“硬凑、割裂”时回到语义，不能只把同一组标签换边框、换颜色。内容关系未稳定时，增加装饰通常不能解决问题。

## 建立阅读顺序，再选视觉表现

按观众的判断顺序分配信息区：先知道是什么及为什么值得看，再看具体内容，最后看到必要条件和下一步行动。长图可用“主标题与价值—详情—行动”组织节奏；课程可将课程名/学习理由、课纲、报名信息分开。单屏主图按用途减量，不强制两屏或固定比例。

先按[公司／项目模板](company-project-templates.md)继承已确认的主题色和默认风格；公司主题色保持不变，构图、字体和材质可以变化。已知品牌色、Logo/吉祥物、是否用真人和必须出现的事实先进入简报。报名区如果尚缺价格或入口，可以按本次要求留位，不能编数字或假码。核心区域不依赖后期补字才成立。

有参考时按[参考拆解](reference-led-design.md)说明其具体构图机制及本项目的替换办法。没有人物需求时，也能采用人物参考中的字形、光线、空间和阅读层级，不因此加真人。

## 比较方案只改变需要判断的维度

用户要求多个风格时，以同一版内容作为比较基础，拉开构图、主视觉、字体与材料关系的差异，避免只是换色。方案数服从本次要求；风格已定时从当前选定稿继续修改。

内容与结构尚不稳定时，先解决它们；不为试错反复生成多套完整风格。给一个有依据的主推荐，必要时提供明确不同的备选，不把助手的推荐当作用户已经选择。

## 把反馈转成具体改动

| 用户反馈 | 优先检查 | 应做的调整 |
|---|---|---|
| 太细、像课件 | 内容粒度 | 合并细节为短主题与业务表达，详细内容留原稿 |
| 太空、没讲具体学什么 | 内容信息量 | 给主题补必要内容点，保持统一长度 |
| 太挤、都砸在一起 | 阅读分区与信息权重 | 调整区域顺序、主次和留白，必要时拆屏/拆页 |
| 硬凑、割裂 | 关键词的角色与关系 | 重新解释内容逻辑，再改图示与组织 |
| 不像参考、没那个感觉 | 构图与材料机制 | 对照主视觉、字形、图文比例和连接方式逐项修正 |
| 太多可爱头像 | 品牌元素的数量与视觉权重 | 缩小或减少角色，保留必要品牌识别 |
| 这部分可以，只加结尾 | 已认可区域与修改目标 | 以该版为编辑目标；新增区明确，完成后复核整张 |

把实际改动和适用范围记入任务。只调整有依据的维度；反馈未否定的内容继续沿用。

## 整张生成、整张核对

按[整张生图](whole-poster-generation.md)使用准确文案、分区、素材角色与参考机制生成完整海报。保留独立文字清单；长图和新增区域的编辑都要对照完整清单检查。[复核](review.md)负责发现问题，不以提示词、OCR或自己认可代替最终图。

选定后，当前入口指向同一版图片与文案。按用户需求归拢资料包或归档候选，保留原文、参考和失败记录。某一张颜色、人物数量、课表天数的认可留在对应案例；本工作法可复用，具体审美仍按当前对象和用途选择。
