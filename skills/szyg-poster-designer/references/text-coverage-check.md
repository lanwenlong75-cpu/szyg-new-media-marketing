# 文字清单辅助核对

仅在长图、密集文案或模型改稿有漏项风险时使用。先有当前完整文案，再把需要保留的信息分为sections和facts；脚本读取既有OCR结果，不操作图片、不自动重生图。

```json
{
  "sections": [
    {"id": "内容组A", "label": "当前主题", "required": ["主题原文", "内容点原文"]}
  ],
  "facts": [{"id": "关键条件", "text": "本期确认的关键文字"}]
}
```

required里的对象也可用`{"id":"自定编号","text":"固定原文","aliases":["已经确认等义的写法"]}`。别名仅来自真实同义写法，不为了让检查通过而增加错误文字。facts可用同样的对象格式。没有至少一项待核文字时脚本报错，防止空清单被当作通过。

```text
python scripts/check_poster_text.py --expected 当前文字清单.json --observed 最终图OCR.json --out OCR核对.json
```

observed支持UTF-8文本，或含Text/Lines字段的OCR JSON。脚本忽略空格和常见标点比对，短文字与数字只做规范化后的完整匹配；较长文本可给近似提示。结果分exact_match、review_match和not_seen。近似与未见都需要回到最终图检查，不等于海报一定有错；全部命中也不代表排版、位置和视觉通过。

脚本对有效输入返回0并输出检查报告；无效输入返回2。它不以OCR未命中自动阻断成图，也不替代设计师检查。报告保留每组情况，避免总命中率掩盖最后一组全部漏掉。
