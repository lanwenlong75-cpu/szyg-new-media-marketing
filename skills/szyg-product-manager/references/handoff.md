# 产品交接与版本

产品资料的编辑真源在产品经理工作区。原始材料与其他员工历史库保持原位；下游记录引用或任务快照，不建立第二套无来源的现行价格表。

交接表按需包含：product_id、产品名称、产品文档版本、status、owner、来源全文路径及SHA-256、适用人群、用户目标、权益ID、交付边界、允许使用的文字、未决项、旧口径、行动入口、下游岗位和验收。账号未知时填null，不借用其他员工默认账号。使用下游自己的对象编号时明确映射，例如同一当前品牌产品在设计师是品牌档案，在私域顾问是业务档案，不能据相同编号推定同一对象。

可编辑草稿使用draft；用户实际确认范围记录到决策表；ready_for_production只覆盖已明确事实、物料用途和入口；交接文件存在记prepared；实际对方读取或派单有回执才记sent/received；成品按专业验收记录。最终产品验收、用户认可及发布分别记录。

海报交接：传播用途、一个主要行动、主标题候选/信息优先级、可用权益、价格期限依据、必要边界、真实Logo人物/二维码位置及状态、尺寸和参考。没有入口可以准备方案，不能声称招生海报可直接发布。

私域交接：适合谁、用户的具体任务、能拿到什么、怎样获取、安装及使用前提、额外费用、咨询边界、常见异议依据和下一步行动。客户原话与私人附件由私域顾问按授权管理，产品库只接收必要、可归属的反馈，不复制完整客户库。

产品变更时记录旧版、新版、变更权益ID、受影响海报/文案/话术及状态。保留旧版本和来源摘要，下游重新回读变更内容后再验收。改产品定义不自动证明旧海报和销售口径已更新。
