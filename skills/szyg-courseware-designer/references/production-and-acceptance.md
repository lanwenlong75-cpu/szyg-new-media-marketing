# 课件制作与验收

## 选择实现

做课件、做PPT、改课件默认交付可编辑PPTX；用户本次指定其他格式或只要脚本/诊断时按本次范围。PPTX/演示文稿使用当前presentations技能，文件级Word讲义使用documents，PDF使用pdf；图像使用当前图像工具。读取适用技能的真实入口和必要引用，按其工具制作，不把技能名称当作已经执行的证据。仅写大纲或逐页讲稿时直接交付文字源文件。

本员工默认采用[用户审美规范](design-system.md)、[教学与改稿规范](teaching-standard.md)及[PPTX规范](pptx-workflow.md)。按模块根目录读取assets/design-tokens.json和六页可编辑样板，落实16:9、深色底、暖黄色、大字、逻辑图解及无页码/重复底部角标。用户另给模板时先查版式、字体、母版、页面尺寸和素材，保留本次明确要求；默认审美不覆盖本次指定风格。在线交互、动画、录播或导出需核对实际播放环境，避免预览依赖不支持的功能。资源包只含实际使用且可交付的素材；私有资料与凭据按原归属保护。

## 逐页组织

每页可以是判断、流程、比较、案例、演示、操作、练习或复盘，围绕当前教学任务安排。主标题讲清该页重点；正文突出必要信息；图表明确单位、图例、关系和数据来源；讲师备注说明展开讲法、示范步骤、提问、预期回答与过渡。没有必要时不增加装饰图。以问、看、算、证、揭、教、做、收选择每页主要动作；作业页简洁分区服务并列字段，流程/循环/比较用对应关系表达，不能一律改成卡片网格。

复杂步骤按学习顺序分步揭示；多步提示词讲解按口播逐句出现，同时提供完整可编辑稿。此要求适用于逐句讲解场景，不自动套到所有页面或取消本次用户要求的完整展示。

讲师备注必须写入PPT notes，不能仅存在独立文档。保留方法名、主图、人物原图与已定顺序；真实证据按指定细节等比放大。样板为可编辑布局集合，正式产物清除示例文字与插槽说明，缺图按用户要求标待补。

## 实际检查

| 检查 | 需要证据 | 不能据此宣称 |
|---|---|---|
| 教学内容 | 对照目标、来源、示例、练习与答案回读 | 学员已学会或实际培训有效 |
| 文件结构 | 成品可打开、页数/顺序正确、编辑对象与声明相符 | 每个元素均可编辑 |
| 视觉 | 渲染成品并按1280×720逐页查看，检查溢出、遮挡、字号/单位、配色、图像比例、证据清晰、箭头、页码/角标及图表 | 仅文本提取即视觉通过 |
| 播放与交互 | 在实际目标环境检查动画/触发/媒体，记录范围 | 静态预览证明动态功能正确 |
| 授课节奏 | 分项时长与实际试讲记录；未试讲标估算 | 预计时长即讲师实测 |
| 用户确认 | 实际人类反馈及其认可部分/版本 | 助手自评或自动检查即用户认可 |

发现问题在当前版本修复，渲染受影响页并检查关联页；模板或批量样式影响全局时复核全部页面。无可用渲染器或目标软件时交付已完成文件与具体未验范围，不写“全部验收通过”。

## 版本与交接

任务归`03-任务与交付/任务ID`，课程当前文件归对应课程档案或在任务中建立明确链接；记录二者真源。交接含课程ID/版本、学员、场景、目标、课程资料版本、制作工具/模板、源文件、预览、备注、练习/答案、来源和验收。新增版本保留旧版并写明影响页/模块。

prepared表示交接资料已备妥；已发送、对方收到、实际发布或正式授课各需真实回执。教学内容与招生权益口径冲突时指出来源与范围，交产品经理处理承诺；不凭课件文字修改长期价格政策。


## 样板使用的检查范围

随包PPTX按原字节保留。首次在当前工具或替换字体后，先渲染所用页；2026-10-21的Artifact Tool只读渲染中，第3页底部短句出现细线横穿文字的显示差异，源XML没有删除线。不要据此把横线穿字当作风格；当前制作应调整或重建受影响元素后重新查看，必要时在目标演示软件复核。当前保留原样板不等于已对所有软件和字体完成兼容修复。
