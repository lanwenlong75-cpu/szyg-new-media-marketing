# 深色暖黄课件审美与排版

## 设计气质

暗色、干净、有力度，有现代编辑排版的层级；少页、大字、真实证据、清楚关系。饱满而不挤，一页一个视觉中心。时尚感来自尺寸、对齐、图像与阅读节奏。

用户的新指示优先。下列数值是这套风格的默认值；示例课题、人物与时段不属于通用设定。

## 颜色与画布

| 用途 | 默认值 | 使用 |
|---|---|---|
| 画布 | 1280×720，16:9 | PPT 使用等比例；竖屏另行适配 |
| 主底色 | #161819 | 深灰黑，避免换回亮底 |
| 暖黄色 | #F9BE4E | 关键词、大数字、箭头、少量品牌锚点 |
| 主文字 | #F4F2EC | 暖白，主要阅读 |
| 次文字 | #A7ABAF | 辅助说明 |
| 细线 | #52595C | 分隔、关联 |
| 次底块 | #222628 | 独立字段、表格、作业分区 |
| 深次底 | #303538 | 局部层级 |

黄色不换成高饱和橙色或荧光蓝。真实截图可保留原本白底，课件画布继续维持深色。

## 网格与字体

- 左右边距约 64–80 px；顶部内容约 52–80 px 起。相关内容共用基线和一致间距。
- 主图常占有效区域的 50%–80%。避免小图套大白框、图很小而四周空很多。
- 中文无衬线。已有参考字体先核实并沿用；跨设备可用具有合法分发依据的思源黑体或 Noto Sans CJK。系统黑体只作后备。
- 正文、标题、强调至少分三档字重。不要拉伸字形、过密字距、全页超粗。
- 本包不分发或嵌入系统商业字体。PPT样板使用Hiragino Sans GB；目标电脑缺少该字体时统一替换为可用中文无衬线字体，再逐页检查换行。嵌入字体时遵循许可证。

| 层级 | PPT字号（pt） | 1280×720参考像素 |
|---|---:|---:|
| 封面、大问题、大结论 | 54–84 | 72–112 |
| 普通标题 | 36–51 | 48–68 |
| 关键数字 | 54–96 | 72–128 |
| 主图标签 | 24–36 | 32–48 |
| 必须阅读的正文 | 21–27 | 28–36 |

PPT points = CSS px × 0.75。60 px 与 60 pt 不能当作同一大小。低于 28 px 的正文需复查；来源优先放备注。拥挤时先删字、拆关系、重构，最后才微调字号。

## 文字与符号

先写讲师会说的人话，再压成标签。每个短语能够回答“谁做什么”或“和前一项是什么关系”。

| 符号 | 关系 | 示例 |
|---|---|---|
| → / ↓ | 顺序、交接 | 准备资料 → 初稿 → 人工验收 |
| ＋ | 组合或并列条件 | 真实资料 ＋ 采用标准 |
| ＝ | 定义、可验证计算 | 3 项 ＋ 2 项 ＝ 5 项 |
| ⇒ | 推导结论 | 输入齐全 ⇒ 再检查执行问题 |
| 回箭头 | 反馈回流 | 验收记录回到知识库 |

不要用等号表示未经证实的因果。箭头与节点中心对齐，连接边缘到边缘，不穿文字、不悬空、不乱拐。独立短语不能随意串成因果。复杂图先减少交叉与斜线。

标题具体、直白；避免“核心能力矩阵”“深度赋能生态”等空泛词。常规图表页约一个标题＋3–5个主标签；正文超过约120汉字时重做取舍。完整逐字稿进备注。

## 不同页面怎样排

### 封面
一句题目或问题占主位，核心词用黄，通常1–2行。品牌与课程名可以在上方，不能挤压主标题。人物封面按用户要求才加入。不堆目录、完整履历与多组卖点。

### 提问和板书
一页只问一个问题，答案先留备注。可在下方给岗位、任务、验收人等落笔线索。留白服务思考，不机械地把每页做成只有一行字。

### 流程、循环、对比
先后画路径，回流画闭环，对比使用同一标准。方法名称和主图一经用户确认直接复用。一个核心方法图有固定名称、顺序和颜色；拆解时可以局部高亮。

### 真实证据
先确定观众必须看清的词、数字或状态，再决定裁切和尺寸。保持比例，多张含小字截图不用缩略拼盘；可逐张展示、局部放大或拆页。原图保留。重排统计图保留单位、来源、估算标记，不能把估计变成调查事实。

生成插画只能承担示意，不能冒充企业实拍、工具截图或真实人物。缺图时明确待补位。

### 配图丰富
用户要求丰富时，优先增加真实案例、培训现场、作品、系统、细节放大和关系图。整套在大字、证据、图解、任务之间变化节奏。不要靠每页塞更多文字和装饰制造丰富。

品牌剪影可作低干扰锚点，一页通常只用一个，不铺满、不盖字、不为每个标签加图标。板书课可以减少装饰。圆角卡片、胶囊、渐变、小图标和阴影不同时叠加为“AI风”。

### 人物
使用当前确认的原图；脸、肩宽和身体比例不变。抠图使用可用图像工具，检查发际、衣领、手部边缘。左右、半身、大小、前后图层以本次要求为准，不沿用其他课程的排位。反馈变形时回到原图重新等比放置，检查重复变换和裁切。

### 作业和拍照页
独立字段可用简洁分区或表格。写清当前动作、成品、完成信号；拍走后能照着执行。卡片只服务并列字段，不能替代流程关系。

## 页码、角标、动效

- PPT 画面默认无页码、总页数、底部场次和重复讲师署名。
- 必要身份放封面、介绍页或备注。每页下方的“第一天下午／第一天晚上／姓名”默认移除。
- PPT正常保留内部页序；投影画面去掉页码、总页数和重复角标。
- 常规动效只用无、逐项出现和局部高亮，顺序服务话术。

## 反例修正

| 问题 | 改法 |
|---|---|
| 亮底、橙色，偏离品牌 | 深色底、暖黄色、暖白 |
| 图很小，外框很大 | 放大图、去外框、少解释 |
| 六个卡片装六段话 | 先判断流程、对比、循环等关系 |
| 词堆在一起看不懂 | 补清动作与关系，再用符号表达 |
| 很多装饰，证据很小 | 证据占主位，减装饰 |
| 整套每页都同款 | 按问、证、教、做改变版式 |
| 人像拉宽、压扁 | 从原图等比缩放，重新裁切 |
| 箭头悬空或不对齐 | 对齐节点中心，连接边缘 |
| 截图容器大，原字很小 | 裁出关键证据再放大 |
