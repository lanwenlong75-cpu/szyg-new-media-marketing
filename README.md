## 下载后怎么用

1. 下载所需岗位的ZIP，**完整解压**。
2. 打开包内的 **安装提示词.txt**，复制其中的文字给你正在使用的Codex或WorkBuddy助手。
3. 把解压后的文件夹交给助手，按包内「先读我」完成安装、创建项目，再提供自己的资料和任务。

单岗包只安装对应岗位。需要多个岗位时分别下载；需要整套时可[下载全部11个岗位合集（ZIP）](https://github.com/lanwenlong75-cpu/szyg-new-media-marketing/releases/download/v1.0.0-skills.2026.11.04.2/%E6%96%B0%E5%AA%92%E4%BD%93%E6%95%B0%E5%AD%97%E5%91%98%E5%B7%A5_2026.11.04.2_%E7%8B%AC%E7%AB%8BSkill%E5%90%88%E9%9B%86.zip)。已有版本先备份和迁移，保留自己的资料与本地改进。

## 让助手直接下载一个岗位

把下面的「短视频编导」换成你需要的岗位名，复制给能访问GitHub的助手：

```text
请打开 https://github.com/lanwenlong75-cpu/szyg-new-media-marketing，从首页「选择岗位，直接下载」中下载「短视频编导」的单岗ZIP安装包，核对该版本附件的SHA-256并完整解压。读取先读我.md，按我使用的Codex或WorkBuddy安装这个岗位并创建或接入我的项目，保留已有资料和本地改进。完成后告诉我安装的岗位、版本和使用入口。
```
