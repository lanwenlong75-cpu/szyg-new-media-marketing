# 新媒体营销数字员工 Skill

一个 Codex 统一入口，当前公开版来自总入口 **0.2.7**，包含新媒体主管、视频制作引擎、编导、运营、公众号编辑、海报设计、私域顾问、全栈工程、产品经理、数字员工搭建、小红书运营、课件打造及两项归档能力。各模块仍有独立的适用条件和验收。详情见 [版本清单](SOURCE-VERSIONS.json)。

## 安装

在 Codex 中发送本仓库链接并说：**“帮我安装这个仓库里的 `skills/szyg-new-media-marketing`，并按 README 初始化我的团队与项目。”** Codex 可使用内置 skill-installer 从本仓库安装。此路径仅有一个可发现的 `SKILL.md`；内部岗位位于 `capabilities/<岗位>/GUIDE.md`。

需要带完整性检查、旧入口归档和空团队初始化时，克隆仓库后运行：

```powershell
python install.py --archive-legacy
```

Windows 也可运行 `Install-Codex-Windows.cmd`。安装前先读[开始使用](开始使用.md)，安装后用 `python <已安装skill目录>/scripts/portable.py doctor` 检查本机环境。若只用 Codex skill-installer 安装，随后运行 `portable.py init --root <你自己的团队目录>`；已有项目用 `portable.py bind` 接入。已有本地修改或跨发行版升级时先比对与迁移，安装器会保留现状并停止。
